# 📦 Mangosteen Edge AI Models Directory

โฟลเดอร์นี้เป็นพื้นที่สำหรับ**วางไฟล์โมเดล TFLite INT8 ที่คุณเทรนเสร็จแล้ว** เพื่อเตรียมแฟลชลงบอร์ด ESP32-S3

---

## 🚀 ขั้นตอนการใช้งาน

1. **เทรนโมเดลของคุณ:**  
   ศึกษาขั้นตอนการเตรียม Dataset และเทรนโมเดลบน Google Colab ได้ที่คู่มือ:  
   👉 [**TRAINING_GUIDE.md**](../TRAINING_GUIDE.md)

2. **วางไฟล์โมเดล `.tflite` ในโฟลเดอร์นี้:**  
   หลังจากเทรนและแปลงเป็น Full INT8 Quantization แล้ว ให้นำไฟล์มาวางในโฟลเดอร์นี้ เช่น:
   ```text
   models/
   ├── README.md
   └── my_model_int8.tflite   <-- วางไฟล์โมเดลของคุณที่นี่
   ```

3. **แฟลชลงบอร์ด ESP32-S3:**  
   เปิด Terminal ที่ Root ของโปรเจกต์แล้วรัน:
   ```bash
   python setup.py
   ```
   *(หรือดับเบิลคลิกไฟล์ `setup.bat` บน Windows)*  
   สคริปต์จะค้นหาโมเดลในโฟลเดอร์นี้ แปลงเป็น C++ Array และคอมไพล์แฟลชลงบอร์ดให้อัตโนมัติทันที!

---

## ⚙️ ข้อกำหนดของโมเดลสำหรับ ESP32-S3
- **ขนาดภาพ (Input Shape):** `96 × 96 × 3` (RGB)
- **ประเภทข้อมูล:** Full Integer Quantization (`int8` ช่วง `[-128, 127]`)
- **จำนวนคลาส:** 3 คลาส (`0: overripe`, `1: ripe`, `2: unripe`)
