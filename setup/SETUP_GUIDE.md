# คู่มือการติดตั้งและใช้งานระบบ Mangosteen Edge AI (ESP32-S3)
**โครงงานจำแนกระดับความสุกของมังคุดด้วย AI บนบอร์ด LilyGO T-SIMCAM (ESP32-S3)**

คู่มือนี้สรุปขั้นตอนทั้งหมดตั้งแต่ต้นจนจบอย่างละเอียด เพื่อให้ผู้ร่วมทีมหรือบุคคลอื่นสามารถนำไปทำตามบนเครื่องคอมพิวเตอร์และบอร์ดชุดใหม่ได้อย่างถูกต้อง 100%

---

## 1. ข้อมูลฮาร์ดแวร์และข้อควรระวังสำคัญ (Hardware Reality)

### สเปกบอร์ดที่ใช้งาน:
- **บอร์ด:** LilyGO T-SIMCAM (ESP32-S3 Dual-Core @ 240MHz, 16MB Flash, 8MB OPI PSRAM)
- **เซนเซอร์กล้อง:** OV2640 Camera Sensor
- **พอร์ตเชื่อมต่อ:** USB Type-C (ESP32-S3 Native USB CDC, Hardware ID: `303A:1001`)

### ⚠️ ข้อควรระวังพิเศษที่ต้องรู้ (Critical Hardware Gotchas):
1. **บอร์ดรุ่นนี้ไม่มีชิป PMU (AXP2101):**
   - โค้ดตัวอย่างส่วนใหญ่ในอินเทอร์เน็ตของ LilyGO มักเป็นรุ่น *T-Camera S3* ซึ่งต้องเปิดไฟเลี้ยงผ่านชิป AXP2101 บนพิน I2C (4, 5)
   - แต่สำหรับรุ่น **T-SIMCAM** นี้ **ไม่มีชิป AXP2101** และการเปิดไฟเลี้ยงบอร์ดต้องสั่งผ่าน **GPIO 1** (`PWR_ON_PIN = 1`) ให้เป็น `OUTPUT` และจ่าย `HIGH`
2. **ตำแหน่งพินกล้อง (Pin Mapping) ของ T-SIMCAM:**
   - ขา **XCLK คือ GPIO 14** (ไม่ใช่ 15 หรือ 38)
   - ขา Data D0–D7: `11, 9, 8, 10, 12, 17, 16, 15`
   - ขา VSYNC: `6`, HREF: `7`, PCLK: `13`, SCCB SDA: `4`, SCCB SCL: `5`
3. **การปรับโฟกัสเลนส์กล้อง (Manual Focus):**
   - โมดูลกล้อง OV2640 ตั้งระยะโฟกัสโรงงานไว้ที่ระยะไกล (Infinity)
   - หากส่องมังคุดในระยะใกล้ (< 20 ซม.) แล้วภาพเบลอ **ให้ใช้มือค่อยๆ หมุนเกลียวรอบกระบอกเลนส์** เพื่อปรับโฟกัสให้ชัดคมกริบ

## 2. สิ่งที่ต้องติดตั้งล่วงหน้า (Prerequisites)

1. **Python 3.10 ขึ้นไป (สำหรับคอมพิวเตอร์):**
   - ตรวจสอบใน Terminal: `python --version`
   - ตรวจสอบว่าได้ติ๊กเลือก `Add python.exe to PATH` ขณะติดตั้ง
2. **VS Code + PlatformIO IDE (หรือติดตั้ง PlatformIO ผ่าน pip):**
   - ติดตั้ง [VS Code](https://code.visualstudio.com/)
   - ติดตั้งส่วนขยาย **PlatformIO IDE** จาก Extensions Marketplace
3. **ไดรเวอร์ USB Serial:**
   - บอร์ด ESP32-S3 เสียบสายแล้วจะขึ้นเป็น `USB Serial Device (COMx)` โดยอัตโนมัติบน Windows 10/11

## ⚡ วิธีที่ 1: เซ็ตอัพอัตโนมัติในคำสั่งเดียว (แนะนำ)

ถ้าต้องการความสะดวกรวดเร็ว แค่เสียบสายบอร์ด ESP32-S3 เข้ากับคอมพิวเตอร์:

### บน Windows:
ดับเบิลคลิกไฟล์ **`setup.bat`** ได้ทันที

### บน Command Prompt / PowerShell / macOS / Linux:
```bash
python setup.py
```

### ตัวเลือกเพิ่มเติมของคำสั่ง `setup.py`:
- **ระบุพอร์ต COM โดยตรง:**
  ```bash
  python setup.py --port COM7
  ```
- **เลือกโมเดลอื่นที่จะแฟลช (เช่น Basic CNN):**
  ```bash
  python setup.py --model models/basic_cnn_int8.tflite
  ```
- **คอมไพล์อย่างเดียวโดยไม่ต้องอัปโหลด:**
  ```bash
  python setup.py --build-only
  ```

### สิ่งที่สคริปต์ `setup.py` จัดการให้แบบอัตโนมัติ:
1. ตรวจเช็คและติดตั้งไลบรารี Python ที่จำเป็น (`pyserial`, `numpy`, `pillow`, `platformio`)
2. แปลงไฟล์โมเดล `.tflite` เป็น C++ array ลง `src/` ให้อัตโนมัติ
3. สแกนหาพอร์ต USB ของบอร์ด ESP32-S3 อัตโนมัติ
4. คอมไพล์และแฟลชเฟิร์มแวร์ลงบอร์ดทันที พร้อมแสดงข้อความยืนยันเมื่อเสร็จสิ้น

## 🛠️ วิธีที่ 2: ขั้นตอนการตั้งค่าแบบ Manual ทีละสเต็ป

### ขั้นตอนที่ 1: ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### ขั้นตอนที่ 2: แปลงโมเดล TFLite เป็น C++ Array
เลือกโมเดลที่ต้องการจากโฟลเดอร์ `models/` แล้วสั่งแปลง:
```bash
# ตัวอย่าง: แปลงโมเดลหลัก MobileNetV2 alpha 0.35
python convert_tflite_to_c.py models/mobilenet_v2_alpha35_int8.tflite --out-dir src
```
*ผลลัพธ์ที่ถูกต้อง:* จะได้ไฟล์ `src/mangosteen_model_data.h` และ `src/mangosteen_model_data.cc` ที่มีขนาดตรงกับไฟล์โมเดล

### ขั้นตอนที่ 3: คอมไพล์และแฟลชโค้ดลงบอร์ด
```bash
# คอมไพล์และอัปโหลด (PlatformIO จะค้นหาพอร์ตให้อัตโนมัติ)
pio run -t upload

# หรือระบุพอร์ตโดยตรง
pio run -t upload --upload-port COM7
```

## 5. วิธีเข้าใช้งานและทดสอบระบบ

มี 2 รูปแบบให้เลือกใช้ตามความสะดวก:

### 🌐 วิธีที่ 1: ดูผ่าน Web Browser (แนะนำที่สุด — ไม่ต้องลงโปรแกรมเพิ่ม)
วิธีนี้เหมาะกับการพกพาไปสาธิต หรือใช้สมาร์ทโฟน / แท็บเล็ต ส่องดูมังคุดได้แบบไร้สาย:

1. **เชื่อมต่อ Wi-Fi จากบอร์ด:**
   - ค้นหา Wi-Fi ชื่อ: **`Mangosteen-AI`**
   - รหัสผ่าน: **`12345678`**
2. **เปิดเบราว์เซอร์:**
   - เปิด Chrome, Safari หรือ Edge แล้วพิมพ์ URL: **`http://192.168.4.1`**
3. **การใช้งานหน้า Dashboard:**
   - **กรอบเล็งเป้า (Target Box):** ส่องกล้องให้ลูกมังคุดอยู่ตรงกลางกรอบ
   - **ปุ่ม `📸 ถ่ายภาพ & Predict`:** กดถ่ายเมื่อจัดมุมเสร็จ หน้าจอจะล็อกภาพเฟรมนั้นและแสดงผลทำนาย:
     - ป้ายสถานะสี: `🎯 RIPE` (สีเขียว), `UNRIPE` (สีส้ม), `OVERRIPE` (สีแดง)
     - แถบเปอร์เซ็นต์ความมั่นใจ (%)
     - เวลาในการประมวลผล (Inference Latency ในหน่วย ms)
   - **ปุ่ม `🔄 กลับไปดูภาพสด`:** กดเพื่อปลดล็อกกลับมาดูวิดีโอสดสำหรับส่องลูกถัดไป
   - **สวิตช์ `⚡ วิเคราะห์สดต่อเนื่อง (Auto-AI)`:** สลับให้ AI ทำนายผลอัตโนมัติตลอดเวลา

### 💻 วิธีที่ 2: ดูผ่านหน้าต่างโปรแกรมบนคอมพิวเตอร์ (Python GUI)
กรณีต้องการดูภาพสดและกดถ่ายผ่านสาย USB ต่อตรงกับคอมพิวเตอร์:

1. เสียบสาย USB เข้ากับคอมพิวเตอร์

   - แสดงภาพสด 384x384 (ขยายคมชัดจากตัวกล้อง)
   - กดปุ่ม **`Spacebar`** บนคีย์บอร์ด หรือคลิกปุ่ม **`📸 ถ่ายภาพ & Predict`** เพื่อดูผลทำนาย

## 6. ปัญหาที่พบบ่อยและการแก้ไข (Troubleshooting)

| อาการที่พบ | สาเหตุ | วิธีแก้ไข |
|---|---|---|
| อัปโหลดโค้ดไม่ผ่าน `Could not open COMx` | พอร์ต COM ถูกโปรแกรมอื่นใช้งานอยู่ (เช่น Tera Term หรือ Python GUI) | ปิดหน้าต่าง Tera Term / Python แล้วสั่งอัปโหลดใหม่ |
| กล้องไม่ทำงาน `Init Failed 0x105` | พินกล้องไม่ตรง หรือลืมเปิดไฟเลี้ยงบอร์ด | ตรวจสอบว่าในโค้ดมี `pinMode(1, OUTPUT); digitalWrite(1, HIGH);` และใช้พินของ T-SIMCAM (XCLK=14) |
| ภาพเบลอมาก ไม่ชัด | เลนส์กล้องหลุดระยะโฟกัส | ใช้มือค่อยๆ หมุนเกลียวรอบกระบอกเลนส์กล้อง OV2640 เพื่อปรับระยะชัดตามที่ต้องการ |
| ตัวหนังสือใน Serial Monitor เอียงเป็นขั้นบันได | โปรแกรมรับค่าขึ้นบรรทัดใหม่ไม่ครบ | ตั้งค่า Terminal ให้ขึ้นบรรทัดใหม่แบบ `CR+LF` |
| หา Wi-Fi `Mangosteen-AI` ไม่เจอ | บอร์ดยังบูตไม่เสร็จ หรือเสาอากาศหลวม | กดปุ่ม **RST** เล็กๆ บนบอร์ด 1 ครั้ง รอ 3 วินาทีแล้วค้นหา Wi-Fi ใหม่อีกครั้ง |
| โมเดลรันแล้วขึ้น AllocateTensors() failed | ขนาด Tensor Arena ไม่เพียงพอ | ตรวจสอบว่าเปิด PSRAM ใน `platformio.ini` เรียบร้อยแล้ว (`-D BOARD_HAS_PSRAM`) |
